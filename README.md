# 轻待办

一款本地运行、支持多账号和专注时钟的轻量待办网页。

“轻待办”围绕每天的待办事项设计：每个账号拥有独立的数据空间，可以创建多个分表，按日期组织任务，并通过拖拽、完成动画和专注倒计时保持清单清晰、安静。

## 功能

- 本地注册和登录，不使用邮箱或手机号。
- 多账号数据隔离，每个用户只能访问自己的任务。
- 首页总表汇总当天的待办事项。
- 支持多个独立分表，不同分表使用低饱和颜色区分。
- 任务包含名称、日期和所属分表。
- 未完成、逾期和已完成视图相互独立。
- 同一日期内支持手动拖拽排序。
- 支持跨分表拖动，也可以从列表左右边缘连续切换分表。
- 完成后任务进入“已完成”视图，支持恢复和永久删除。
- 删除分表时，可选择转移事项或连同事项一起删除。
- 每个未完成事项提供“现在做”入口。
- 专注模式支持自定义倒计时、暂停、继续和重新计时。
- 提供四卡单数字翻页钟与剩余分钟刻度圆形钟。
- 专注倒计时会保存在浏览器本地，刷新后可恢复。

## 技术栈

| 模块 | 技术 |
| --- | --- |
| 前端 | 原生 HTML、CSS、JavaScript |
| 后端 | Node.js 原生 HTTP 服务 |
| 数据库 | SQLite（`node:sqlite`） |
| 密码处理 | Node.js `crypto` / scrypt |
| 图标 | 内联 SVG |
| 依赖 | 无第三方运行时依赖 |

项目没有使用 React、Vue、Express 或其他前后端框架。

## 环境要求

- Windows 10 或 Windows 11
- Node.js 24 或更高版本

Node.js 需要包含内置的 `node:sqlite` 模块。当前使用的版本为 `v24.22.1`。

## 本地运行

克隆仓库：

```bash
git clone https://github.com/Wiiinee/todo-app.git
cd todo-app
```

启动服务：

```bash
node server.js
```

默认访问地址：

```text
http://127.0.0.1:4173
```

服务启动后会自动尝试打开默认浏览器。关闭命令窗口即可停止服务。

> 不要直接双击 `public/index.html`。页面需要本地后端提供账号、数据和 API，必须通过 `node server.js` 启动。

## 首次使用

1. 打开登录页。
2. 切换到“创建账号”。
3. 输入用户名和密码。
4. 注册后会自动创建默认分表“我的待办”。
5. 点击“记一件事”添加任务。

## 数据保存

本地数据保存在：

```text
data/light-todo.db
```

数据库文件不会提交到 Git。备份时关闭服务，复制整个 `data` 文件夹即可。

当前版本的数据只保存在运行服务的电脑上，不支持多台电脑之间自动同步。

## 项目结构

```text
todo-app/
├─ public/
│  ├─ index.html       # 页面结构
│  ├─ styles.css       # 视觉样式和动画
│  └─ app.js           # 页面交互、拖拽和专注倒计时
├─ data/               # 本地 SQLite 数据，不提交到 Git
├─ server.js           # HTTP 服务、账号、任务与数据库接口
├─ launcher.ps1        # PowerShell 启动辅助脚本
├─ 启动轻待办.cmd      # 当前开发电脑的中文启动入口
├─ 使用说明.md         # 中文使用说明
└─ README.md
```

> 仓库中的 `启动轻待办.cmd` 绑定当前开发电脑的 Node.js 安装位置。其他电脑克隆项目后，请直接运行 `node server.js`。

## 主要交互

- 按住任务约 `0.1` 秒后可拖动。
- 同一日期内可以调整任务顺序。
- 任务拖到列表左右边缘并停留，可切换相邻分表。
- 分表标签可以按住拖动，调整左右顺序。
- 勾选完成后，任务会折叠消失并进入“已完成”。
- 专注页面支持翻页钟和圆形钟两种显示方式。

## 数据与安全说明

- 服务默认只监听 `127.0.0.1`，不能被局域网或互联网中的其他电脑直接访问。
- 密码使用带随机盐的 scrypt 哈希保存，不以明文写入数据库。
- 当前没有邮箱或手机号，因此不提供密码找回。
- 当前版本适合本地和小规模个人使用。
- 如果部署到互联网，应增加 HTTPS、登录频率限制、数据备份和正式域名，并重新检查隐私与安全配置。
